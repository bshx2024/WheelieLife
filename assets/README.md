# Assets Folder

## Required Images

Please add the following images to this folder:

### Moto X3M Screenshots
1. **moto-x3m-1.png** - First screenshot of Moto X3M game (the one you provided)
2. **moto-x3m-2.png** - Second screenshot of Moto X3M game (the one you provided)

Both images should show the motorcycle racing gameplay with the cyan/blue bike.

### Recommended Image Specifications
- Format: PNG or JPG
- Recommended width: 800-1200px
- Aspect ratio: 16:9 or similar
- File size: Optimized for web (< 500KB each)

## Note
The images you provided in the chat should be saved as:
- `moto-x3m-1.png` (first screenshot)
- `moto-x3m-2.png` (second screenshot - can be the same or different angle)

These will be displayed on both the homepage game card and the Moto X3M game page.
